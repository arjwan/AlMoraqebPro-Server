# تطبيق AlMoraqeb Pro لسطح المكتب

تشغيل نسخة التطوير:

```bash
npm install
npm run desktop
```

إنشاء حزم التثبيت للنظام الحالي:

```bash
npm run desktop:build
```

ينتج `AppImage` و`deb` على Linux، و`NSIS exe` على Windows، و`dmg` على macOS. يجب تنفيذ البناء على كل نظام مستهدف للحصول على حزمته الأصلية.

يفتح التطبيق خدمة المراقب برو المنشورة داخل نافذة مستقلة بلا أشرطة متصفح. بعد أول تشغيل ناجح وتسجيل دخول أثناء توفر الإنترنت، تحتفظ الجلسة ببيانات Offline والملفات المخزنة محليًا لاستخدامها عند انقطاع الاتصال ثم مزامنتها عند عودته.
